# CineDairy — личный центр кино

Веб-приложение с гостевым режимом и серверными аккаунтами: коллекция фильмов и сериалов, отдельные просмотры, цитаты, личные подборки и сохраняемые фильтры. Дизайн — чёрный, матовое золото и тёплые оттенки домашнего кинозала.

## Как пользоваться

- **Добавить просмотр:** новый фильм или выбор из архива. Повторный просмотр сохраняет собственную дату, оценку, компанию, настроение и заметку.
- **Карточка фильма:** открывается поверх коллекции, не сбрасывая фильтры и прокрутку. Разделы «Обзор», «Просмотры», «Цитаты».
- **Цитатник:** текст, персонаж, время сцены, комментарий, тематические теги. Спойлеры скрыты до нажатия. Есть копирование и поиск.
- **Коллекция:** постеры или список; фильтры по жанру, типу, последней оценке, наличию цитат/заметок, датам, повторным просмотрам, тегам, компании, настроению и подборке. Условия работают вместе. Дата, компания и настроение должны совпасть в одной записи просмотра. Сочетания условий сохраняются по имени.
- **Подборки:** добавление одного или нескольких фильмов, изменение порядка стрелками. Удаление подборки не удаляет фильмы.
- **Дневник:** все просмотры или выбранный месяц, включая записи без даты.
- **Общий поиск:** названия, сведения, заметки и цитаты. Клавиша `/` переводит фокус в поиск.
- **Киноопыт:** число фильмов, просмотров, цитат и пересмотров. Нажатие на жанр открывает соответствующую коллекцию.
- После удаления доступна кнопка **«Отменить»** в уведомлении. Она действует до следующего изменения архива или закрытия уведомления.

## Данные и совместимость

В гостевом режиме архив сохраняется в текущем браузере. После развёртывания серверной версии доступны вход по email и Яндекс ID, PostgreSQL и синхронизация. В аккаунте архив хранится на сервере, а в браузере — только в памяти вкладки; гостевой архив автоматически не загружается и не удаляется. Страница «Резервные копии и данные» экспортирует и восстанавливает полный JSON. При импорте архив заменяется после подтверждения; предыдущая версия сохраняется в `cinedairy.before-import`.

При первом запуске старые ключи `movies` и `watchlist` автоматически переносятся в `cinedairy.archive.v2`. Каждый старый фильм сохраняет свой просмотр, оценку и комментарий. Исходные ключи не удаляются. Одинаковые названия не объединяются автоматически, чтобы не потерять независимые записи. Для новых пересмотров выбирайте существующий фильм.

Повреждённый архив не сбрасывается автоматически: приложение предлагает скачать исходные данные. Ошибка записи или изменение в другой вкладке не перезаписывают сохранённую коллекцию. Перед очисткой данных браузера скачайте полную резервную копию.

Схема v2: `movies`, `views`, `quotes`, `collections`, `presets`. Связи строятся по идентификаторам. Оценка на карточке — оценка последнего по дате просмотра. Средняя оценка в статистике учитывает каждый оценённый просмотр; записи без оценки исключены.

На серверной версии ключ Kinopoisk задаётся владельцем в переменной `KINOPOISK_API_KEY`; поиск идёт через сервер и доступен после входа. На статической версии для автоматического поиска добавьте собственный API-ключ Kinopoisk Unofficial в разделе «Резервные копии и данные» → «Настроить автопоиск». Ключ хранится только в текущем браузере, передаётся сервису поиска и не попадает в экспорт архива. Пустое поле настройки удаляет ключ. При отсутствии ключа или недоступности API доступно ручное добавление. Секреты сервера не включаются в исходники, резервные копии пользовательского архива или ответы API.

## Запуск гостевого режима

Сборка для публикации не требуется. Для гостевого режима разместите `index.html`, `styles.css`, `quote-card.css`, `model.js`, `account.js`, `quote-card.js` и `app.js` в одной папке статического хостинга (в том числе GitHub Pages).

Для локального просмотра из папки проекта:

```sh
python3 -m http.server 8000
```

Откройте `http://localhost:8000`.

## Проверки

Модель данных проверяется без зависимостей:

```sh
node --test tests/model.test.cjs
```

Браузерные проверки:

```sh
npm install
npx playwright install chromium
npm run test:ui
```

Можно передать путь к установленному Chromium через `CHROMIUM_PATH`, а папку для снимков — через `SCREENSHOT_DIR`. Тесты используют изолированный браузер и тестовые ответы API, не обращаются к реальной коллекции и не изменяют репозиторий.

Файлы: `model.js` — схема, перенос, проверка и фильтрация данных; `app.js` — интерфейс и действия; `styles.css` — адаптивная тема; `tests/` — регрессионные проверки.

## Серверные проверки

```sh
python -m venv .venv
.venv/bin/pip install -r server/requirements.txt
FILM_TEST=1 .venv/bin/python server/manage.py test cinema
FILM_PYTHON=.venv/bin/python npm run test:account
```

Без PostgreSQL два теста блокировок пропускаются. Workflow `.github/workflows/checks.yml` запускает полный набор на PostgreSQL, проверку восстановления зашифрованной копии и браузерные сценарии. Почта и Яндекс в тестах подменены; реальные провайдеры подключаются и проверяются после настройки владельцем.

Сервер сохраняет архив одной транзакцией с общей версией. При конфликте изменений интерфейс предлагает скачать несохранённую копию и загрузить актуальную. Автоматического слияния и редактирования аккаунта офлайн пока нет. Максимум JSON — 10 МБ; ограничения количества записей указаны в `server/cinema/validation.py`.

Перенос гостевого архива в аккаунт требует подтверждения и добавляет записи к существующим. Одинаковые фильмы сохраняются отдельными записями, исходная гостевая копия остаётся в браузере. Повторный перенос того же содержимого не дублирует записи. Для явной замены архива используйте экспорт/восстановление с предварительным сохранением обеих копий.
